# Disease Prediction Using Machine Learning

## Project Overview
This project demonstrates how machine learning can identify patterns in medical data and predict a diabetes-related outcome using Python.

## Objective
To build and evaluate a classification model using the Pima Indians Diabetes dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab
- GitHub

## Machine Learning Workflow
1. Load and explore the dataset.
2. Inspect missing values, duplicates, and unusual zero values.
3. Split the data into training and testing sets.
4. Handle missing measurement values using median imputation.
5. Scale features and train a Logistic Regression model.
6. Evaluate the model using accuracy.
7. Test a sample prediction.

## Results
- Training accuracy: approximately 77.69%
- Testing accuracy: approximately 76.62%

## Limitations
This is an educational project. It is not clinically validated and must not be used to diagnose diabetes or make medical decisions.
